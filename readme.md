# 📘 4 Pillars of Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming paradigm that organizes code using objects and classes. It is widely used to build scalable, maintainable, and reusable software systems.

---

## 🚀 The 4 Pillars of OOP

### 1️⃣ Encapsulation  
Encapsulation is the concept of wrapping data and methods into a single unit (class) while restricting direct access to some parts of the object. It helps protect data and ensures controlled interaction through methods.

---

### 2️⃣ Inheritance  
Inheritance is the mechanism that allows one class to acquire the properties and behaviors of another class. It promotes code reuse and helps build a hierarchical relationship between classes.

---

### 3️⃣ Polymorphism  
Polymorphism means "many forms." It allows the same method or interface to behave differently depending on the object or context, improving flexibility and scalability in code.

---

### 4️⃣ Abstraction  
Abstraction is the process of hiding complex implementation details and showing only the essential features of an object. It helps reduce complexity and improves code clarity.

---

## 🎯 Summary

| Pillar        | Purpose                                  |
|--------------|------------------------------------------|
| Encapsulation | Protect data and control access          |
| Inheritance   | Reuse existing code                      |
| Polymorphism  | Enable flexible behavior                 |
| Abstraction   | Hide complexity and show essentials      |

---

## ✨ Conclusion

The four pillars of OOP help developers design clean, efficient, and maintainable applications by promoting structure, reusability, and simplicity.
